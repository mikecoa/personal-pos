# Orda

## Reply style

Use the `caveman` skill for every chat reply in this project, from the first reply of a session, until someone says "stop caveman" or "normal mode". It is installed in `~/.claude/skills/caveman` (source: https://github.com/juliusbrussee/caveman).

This covers chat only. Code, comments, commit messages, PRs, docs and anything else saved outside the chat stay in normal, full sentences.
